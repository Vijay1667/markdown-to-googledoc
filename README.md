# markdown-to-googledoc
This python script converts markdown file into google doc file and give you the link.

Requirements:

### Installation


```python
pip install --upgrade google-api-python-client google-auth-httplib2 google-auth-oauthlib
```
Download / Open the .ipynb file.

Then click on Run All button in the notebook.

Authentication (Signin) with edit access must be provided to save the google doc and to get a valid link.
